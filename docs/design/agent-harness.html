核心升级 1：Harness 驱动的 Agent 自进化系统

Agent Schema → 自进化循环
📋 Schema 层（每个 Agent 的 Harness 配置）
purpose.md
Agent 存在目的、核心问题、分析范围
schema.md
工作流规则、输出格式、工具使用协议
tools.yaml
工具注册表、参数 Schema、调用策略
evolution.md
进化历史：哪些改动、为什么、效果如何
🔄
🧬 自进化循环（每次分析会话后触发）
📊 收集信号
工具命中率 · 用户修正 · 代码执行成功率 · 用户评分
→
🔍 Lint 自审
低效工具检测 · 提示词盲区 · 重复任务模式发现
→
💡 生成建议
新增工具候选 · Schema 优化 · 提示词调整
→
✅ 人工审核
用户确认/拒绝建议 → 更新 Schema → 记录 evolution.md

核心升级 2：两步思维链分析流程

数据分析 Two-Step：分析 → 执行（替代单步代码生成）
🔬 第一步：分析规划
输入：用户消息 + 数据结构 + Schema + purpose.md

LLM 分析输出：
· 数据特征识别（列类型、分布、异常）
· 与历史分析的关联（增量缓存命中）
· 推荐操作序列（工具清单 + 代码）
· 预测结果形态
· 潜在风险和注意事项

→ 展示分析计划给用户确认
▶
⚡ 第二步：批量执行
执行引擎：
· 工具调用优先（毫秒级）
· 代码在 Kernel 中执行
· 并行执行无依赖操作
· 实时流式进度反馈

输出组装：
· 图表 + 表格 + 代码 + 解释
· 每个输出标记来源（数据列、方法）
· 自动生成 index.md 条目
· 追加 log.md 操作记录

→ SHA256 缓存本次分析结果

核心升级 3：数据/模型关联图谱

将 llm_wiki 图谱模型迁移到数据科学领域
📊 数据关联图谱
节点 = 数据列 / 特征 / 数据集
边 = 相关系数 / 衍生关系 / 共享来源

检测：
· 高相关特征对（共线性警告）
· 衍生特征链
· 数据泄漏路径
· 孤立特征（与目标无关）
🧠 模型关联图谱
节点 = 模型实例 / 参数配置 / 评估指标
边 = 继承关系 / 相似配置 / 性能对比

检测：
· 相似模型不同性能 → 调参方向
· 最优模型路径追踪
· 过拟合迹象（train≫val）
· 社区检测：模型家族聚类
🔍 图谱洞察引擎
自动分析图谱结构，生成建议：

惊奇连接：
· 意外的高相关性特征对
· 不同任务间的可迁移特征

知识空白：
· 未探索的特征组合
· 未尝试的模型架构
· 缺少的外部数据源

核心升级 4：持久化操作队列 & 增量缓存

📦 分析任务队列
· ML 训练任务入队，异步执行
· 支持取消、重试、优先级调整
· 崩溃恢复：队列持久化到磁盘
· 进度可视化：前端实时展示
· GPU 任务排队：资源感知调度
⚡ 增量计算缓存
· 数据文件 SHA256 哈希 → 跳过未变更重分析
· 中间结果缓存（describe、corr、特征重要性）
· 代码块哈希 → 相同代码+相同数据 = 重用结果
· 缓存失效策略：数据变更自动清除关联缓存
📝 操作日志 log.md
· 每条操作追加时间戳记录
· 可解析格式：grep 过滤、统计分析
· 用于 Agent 自我回顾："上次做了什么"
· 会话恢复时快速重建上下文
