自进化系统的三层架构

经验提取 → 模式识别 → 永久沉淀
🔬 第一层：任务结束 → 自动经验提取
每次分析/训练任务完成后，Agent 自动调用 extract_lessons() 进行事后复盘：
✅ 成功经验
"用中位数填充 Age 列效果好于均值，因为 Age 分布右偏"
"先做 log 变换再做标准化，提升了模型收敛速度"
⚠️ 失败教训
"直接删除缺失行导致样本量不足，应该先评估缺失比例"
"未检查特征量纲导致 KMeans 聚类结果被量级大的特征主导"
🔍 发现模式
"当缺失率 > 40% 且非关键列，删除比填充更合理"
"XGBoost 在此类表格数据上持续优于随机森林"
🧬 第二层：跨任务模式聚合 → 经验升华为规则
定期（或积累 N 条经验后），Agent 调用 consolidate_lessons() 进行跨任务归纳：
聚合引擎工作流：
1. 按领域聚类：金融数据 / 时序数据 / 文本数据 / 图像数据
2. 按操作类型聚类：缺失值处理 / 特征工程 / 模型选择 / 超参调优
3. 冲突检测：当两条经验矛盾时，标记由人工裁定
4. 置信度评估：出现 ≥3 次 → 高置信规则；1-2 次 → 低置信建议
5. 时效性衰减：旧规则长时间未被触发，权重缓慢下降
输出：自动规则
"当数据包含 ≥3 个高基数分类变量时 → 优先尝试 CatBoost"
置信度：⭐⭐⭐
来源：3 个项目中 5/5 验证

# 经验：右偏数据优先使用中位数填充缺失值

## 场景
对 sales_2024.csv 的 Age 列（缺失率 2.3%，偏度 2.1）进行缺失值填充。

## 过程
先尝试均值填充 → KS 统计量显著变化 (p < 0.01) → 改用中位数填充 → 分布保持。

## 结论
对于偏度 > 1.5 的数值列，中位数填充比均值填充更好地保持了原始分布形状。

Agent 如何利用进化后的知识

任务启动时的知识注入流程
1 新任务进来 → 系统加载当前 Agent 的 Harness Schema
2 扫描 evolution/rules/ → 匹配当前任务特征
高置信规则自动注入到 System Prompt 中
中置信规则以 "参考建议" 形式注入
冲突规则暂不注入，标记待审核
3 Agent 执行任务，行为被进化知识引导
例如：遇到 "数值列+缺失+偏度>1.5" → 自动推荐中位数填充
而不是每次都从零开始生成通用代码
4 任务完成后 → 本轮结果回写 evolution/，形成闭环
