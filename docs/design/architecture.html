核心数据流：用户发起一次分析请求

👤 用户输入 → WebSocket 发送消息 → API 网关鉴权 → Agent 调度器
  → 意图识别："数据分析任务"
  → LLM Router 选模型：简单任务用 DeepSeek，复杂推理用 Claude
  → Agent 决策：先匹配工具 → 匹配到 detect_missing()
  → 工具返回：{ missing_cols: 3, heatmap_base64: ... }
  → Agent 继续：工具不够 → 生成 Python 代码 → 发送到 Kernel
  → Kernel 执行 → 返回 [stdout, plot_base64, dataframe_json]
  → Agent 组织回复 → WebSocket 流式推送 → 前端渲染
  → 会话记录写入 PostgreSQL
